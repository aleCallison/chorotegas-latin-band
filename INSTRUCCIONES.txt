ACTUALIZACIÓN: LOGIN OBLIGATORIO + SECCIÓN AL REGISTRARSE

QUÉ CAMBIA
- Ya no se puede navegar por Inicio, Integrantes, Eventos, Ensayos, Comunicados o Mensualidades sin iniciar sesión.
- Si alguien intenta abrir una página directamente, será enviado a login.html.
- Después de iniciar sesión volverá a la página solicitada.
- En la navegación, "Ingresar" cambia a "Mi cuenta".
- También aparece "Salir".
- Los administradores/directores reciben además acceso al Panel.

REGISTRO
Ahora el formulario pide:
- Nombre
- Correo
- Sección
- Contraseña

Opciones de sección:
- Sección de Viento
- Percusión
- Cuadros Artísticos
- Otro

La sección se guarda en Supabase en la tabla profiles.

SEGURIDAD
La actualización también cambia las políticas de Supabase para que los datos de:
- Integrantes
- Instrumentos
- Ensayos
- Eventos
- Comunicados
- Reporte público de mensualidades

solo puedan consultarse con una sesión iniciada.

GitHub Pages seguirá siendo un sitio estático y sus archivos HTML/CSS/JS son públicos,
pero la información almacenada en Supabase ya no se entrega a usuarios anónimos.

INSTALACIÓN

1. Descomprime este ZIP.

2. Reemplaza SOLO estos archivos en tu proyecto:
   - login.html
   - js/auth.js
   - js/core.js
   - js/member.js
   - admin/usuarios.html
   - admin/js/usuarios.js

No reemplaces index.html, public.js ni style.css:
así conservas exactamente tus cards, mensualidades y diseño actual.

3. Ve a Supabase > SQL Editor > New query.

4. Abre:
   supabase/migracion_login_obligatorio_secciones.sql

5. Copia TODO el contenido, pégalo en Supabase y presiona Run.

Debe aparecer:
Success. No rows returned

6. Cierra la sesión actual y vuelve a abrir la web.
Ahora al intentar entrar al Inicio sin sesión deberías ser enviado al Login.

7. Prueba registrando una cuenta nueva.
El formulario debe obligar a elegir una de las 3 secciones.

8. Si usas GitHub Pages, sube estos archivos modificados al repositorio y espera a que GitHub vuelva a publicar.

IMPORTANTE
Esta actualización NO incluye js/config.js, así que no borra tu conexión actual con Supabase.
